# Giman Eventos 360

Sistema comercial y operativo de eventos para Grupo Giman Restauración.

## Módulos

- Clientes, espacios y eventos
- Presupuestos con control de versiones
- Anticipos, vencimientos y alertas
- Tareas por responsables y fechas
- Órdenes de servicio para cocina, sala, montaje y proveedores
- Cierres económicos, desviaciones y rentabilidad
- Panel multi-local para Vive Roda, Olympic, Torre del Rame y Tapeoteca

## Desarrollo

Aplicación construida con React, TypeScript, Vinext y Cloudflare D1/Drizzle.

```bash
npm ci
npm run dev
npm run build
```
